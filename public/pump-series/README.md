# Pump Series artwork

Add eight images with the following names (WebP recommended; PNG, JPG and AVIF also supported):

1. end-suction.webp
2. multi-stage.webp
3. sewage.webp
4. in-line.webp
5. split-case.webp
6. self-priming.webp
7. booster.webp
8. fire-fighting.webp

Optional hover artwork: append `-dark`, for example `end-suction-dark.webp`.
Alternatively use `pump1.webp` through `pump8.webp` and `pump1-dark.webp` through `pump8-dark.webp` in the same order.

Until supplied, existing catalog images are used. CSS darkening provides the hover effect without a separate dark image. Refresh development or rebuild production after adding artwork.
